Getting Started

Install the package and start using ngx-chronica in your Angular application.

Install the Package

ngx-chronica is available as the ngx-chronica npm package.

Terminal 
npm install ngx-chronica
Alternative 
yarn add ngx-chronica

Basic Usage

To add a simple date picker to your app:

1. Import the component and styles from ngx-chronica:

TypeScript 
import { ChronicaDatepicker } from 'ngx-chronica';
import 'ngx-chronica/styles.css';

2. Choose a selection mode using the mode prop:

Angular Template 
<chronica-datepicker
  mode="single"
  [selected]=selectedDate
  (selectedChange)=onDateSelect($event)
></chronica-datepicker>

3. Use the selected and selectedChange props to control the selected date:

Component 
export function MyDatePicker() {
  selectedDate: Date | null = null;

  onDateSelect(date: Date) {
    this.selectedDate = date;
  }

  return (
    <chronica-datepicker
      mode="single"
      [selected]=selectedDate
      (selectedChange)=onDateSelect
      [footer]=selectedDate ? `Selected: ${selectedDate.toDateString()}` : "Pick a day."
    />
  );
}
