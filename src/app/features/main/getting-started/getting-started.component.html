Getting Started

Install the package and start using ngx-chronica in your Angular application.

Install the Package

ngx-chronica is available as the ngx-chronica npm package.

Terminal 
npm install ngx-chronica
Alternative 
yarn add ngx-chronica

Quick Start Examples

Choose the component that fits your needs:

📅 DatePicker - Single Date Selection 

import { ChronicaDatepickerComponent } from 'ngx-chronica';

<chronica-datepicker
  [(ngModel)]="selectedDate"
  [config]="{ colorTheme: 'blue' }"
/>

⏰ TimePicker - Time Selection 

import { ChronicaTimePickerComponent } from 'ngx-chronica';

<chronica-time-picker
  [(ngModel)]="selectedTime"
  [config]="{ format24Hour: false }"
/>

📅⏰ DateTimePicker - Date + Time 

import { ChronicaDateTimePickerComponent } from 'ngx-chronica';

<chronica-datetime-picker
  [(ngModel)]="dateTime"
/>

📆 DateRange - Range Selection 

import { ChronicaDateRangeComponent } from 'ngx-chronica';

<chronica-date-range
  [(ngModel)]="dateRange"
/>

⏱️ DurationPicker - Time Spans 

import { ChronicaDurationPickerComponent } from 'ngx-chronica';

<chronica-duration-picker
  [(ngModel)]="duration"
  [config]="{ showHours: true, showMinutes: true }"
/>

🗓️ InlineCalendar - Always Visible 

import { ChronicaInlineCalendarComponent } from 'ngx-chronica';

<chronica-inline-calendar
  [(ngModel)]="selectedDate"
/>
