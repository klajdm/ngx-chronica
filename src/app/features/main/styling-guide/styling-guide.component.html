Dark Mode Support

All components support dark mode with automatic detection or manual control.

☀️ Light Mode

Force light theme regardless of system preference

theme: 'light'

🌙 Dark Mode

Force dark theme regardless of system preference

theme: 'dark'

🔄 Auto Mode

Automatically match system preference

theme: 'auto'

Usage Examples

Basic Theme Configuration

import { ChronicaDatepickerComponent } from 'ngx-chronica';

<chronica-datepicker
  [config]="{ 
    colorTheme: 'purple',
    theme: 'dark'
  }"
/>

Component-Level Theme

export class MyComponent {
  calendarConfig = {
    colorTheme: 'teal',
    theme: 'auto',
    firstDayOfWeek: 1
  };
}

CSS Custom Properties

For advanced customization, override CSS custom properties to create your own theme. 

/* Override theme variables */
chronica-datepicker {
  --chronica-primary: #3b82f6;
  --chronica-primary-hover: #2563eb;
  --chronica-primary-light: #dbeafe;
  --chronica-primary-dark: #1d4ed8;
  --chronica-accent: #60a5fa;
  --chronica-focus: rgba(59, 130, 246, 0.2);
}

Available Variables

  • --chronica-primary - Primary color
  • --chronica-primary-hover - Hover state
  • --chronica-primary-light - Light variant
  • --chronica-primary-dark - Dark variant
  • --chronica-accent - Accent color
  • --chronica-focus - Focus ring

Dark Mode Variables

  • --chronica-bg - Background color
  • --chronica-text - Text color
  • --chronica-border - Border color
  • --chronica-disabled - Disabled state
  • --chronica-hover-bg - Hover background

Styling Tips

💡 Custom Trigger Styling

Style the trigger element (button, input, etc.) using standard CSS classes.

.custom-trigger { /* your styles */ }

🎨 Global Theme Override

Override variables globally in your main styles file for consistent theming.

:root { --chronica-primary: ... }

📐 Responsive Sizing

Components automatically adapt to container size. Use CSS to control width.

chronica-datepicker { width: 100% }

🌓 Dark Mode Detection

Use 'auto' theme to automatically match user's system preference.

theme: 'auto'

Best Practices

  • ✓ Consistent Theming: Use the same color theme across all components for visual consistency
  • ✓ Respect System Preferences: Use 'auto' theme to respect user's dark mode preference
  • ✓ Accessibility: Ensure sufficient color contrast when customizing themes
  • ✓ Brand Alignment: Choose a color theme that matches your brand identity
  • ✓ Testing: Test your theme in both light and dark modes to ensure readability
