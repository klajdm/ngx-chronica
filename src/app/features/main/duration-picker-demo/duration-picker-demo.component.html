Duration Picker Component

Select time spans for booking systems, project management, and time tracking applications. Perfect for scenarios where users need to specify durations like "2 hours 30 minutes" or "3 days 4 hours".

1. Basic Duration Picker

Standard hours and minutes selection for common use cases.

Selected: {{ formatDuration(basicDuration) }}
Total Minutes: {{ getTotalMinutes(basicDuration) }} 
<chronica-duration-picker
  [(ngModel)]="basicDuration"
  [config]="{
    colorTheme: 'blue',
    showHours: true,
    showMinutes: true,
    allowZero: true
  }"
  placeholder="Select duration"
  (durationChange)="onDurationChange($event)">
</chronica-duration-picker>

2. Precision Duration (with Seconds)

Include seconds for precise timing in sports, cooking, or scientific applications.

Selected: {{ formatDuration(precisionDuration) }}
Total Seconds: {{ getTotalSeconds(precisionDuration) }} 
<chronica-duration-picker
  [(ngModel)]="precisionDuration"
  [config]="{
    colorTheme: 'blue',
    showHours: true,
    showMinutes: true,

3. Project Planning Duration

Include days for long-term project planning and resource allocation.

Selected: {{ formatDuration(projectDuration) }}
Total Minutes: {{ getTotalMinutes(projectDuration) }} 
<chronica-duration-picker
  [(ngModel)]="projectDuration"
  [config]="{
    colorTheme: 'blue',
    showDays: true,
    showHours: true,
    showMinutes: true,
    maxDays: 30,
    allowZero: false

4. Form Integration

Seamless integration with Angular forms using ngModel and ControlValueAccessor.

Form Valid: {{ durationForm.valid ? '✅' : '❌' }}
Form Value: {{ formDuration | json }} 
<chronica-duration-picker
  name="workDuration"
  [(ngModel)]="formDuration"
  [config]="{
    colorTheme: 'blue',
    showHours: true,
    showMinutes: true,
    allowZero: false
  }"
  required>
</chronica-duration-picker>

5. Custom Step Intervals

Configure custom step intervals for minutes (15-min blocks) and hours.

Selected: {{ formatDuration(intervalDuration) }}
Total Minutes: {{ getTotalMinutes(intervalDuration) }} 
<chronica-duration-picker
  [(ngModel)]="intervalDuration"
  [config]="{
    colorTheme: 'blue',
    showHours: true,
    showMinutes: true,
    stepHours: 1,
    stepMinutes: 15
  }">
</chronica-duration-picker>

6. Time Tracking with Limits

Set maximum duration limits for time tracking applications.

Selected: {{ formatDuration(trackingDuration) }}
Total Minutes: {{ getTotalMinutes(trackingDuration) }} 
<chronica-duration-picker
  [(ngModel)]="trackingDuration"
  [config]="{
    colorTheme: 'blue',
    showHours: true,
    showMinutes: true,
    maxHours: 12,
    allowZero: false
  }"
  [maxDuration]="{ hours: 8, minutes: 0 }">
</chronica-duration-picker>

7. Dark Theme

Modern dark theme for night-time applications.

Selected: {{ formatDuration(darkDuration) }}
Total Minutes: {{ getTotalMinutes(darkDuration) }} 
<chronica-duration-picker
  [(ngModel)]="darkDuration"
  [config]="{

  }">
</chronica-duration-picker>

Configuration Options

Property Type Default Description
showDays boolean false Show days selector for long durations
showHours boolean true Show hours selector
showMinutes boolean true Show minutes selector
showSeconds boolean false Show seconds selector for precision
maxDays number 365 Maximum selectable days
maxHours number 23 Maximum selectable hours
stepMinutes number 1 Step interval for minutes (e.g., 15 for 15-min blocks)
allowZero boolean true Allow zero duration selection
colorTheme string 'blue' Color theme: blue, purple, green, red, orange, teal, pink, indigo
theme string 'light' UI theme: light or dark

Key Features

  • Multi-unit duration selection (days, hours, minutes, seconds)
  • Quick preset buttons for common durations
  • Customizable step intervals for precise control
  • Duration limits and validation support
  • Real-time duration summary and conversion
  • Angular forms integration (ngModel & Reactive)
  • Multiple color themes & dark mode support
  • Popup-based selection interface
  • Project planning and time tracking ready
  • Responsive design for mobile and desktop
