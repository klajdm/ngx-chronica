Time Picker Component

Interactive time picker component for selecting hours, minutes, and seconds. Supports both 12-hour and 24-hour formats with customizable intervals and restrictions. Perfect for appointment scheduling, meeting setup, and time-sensitive applications.

1. Basic Time Picker (24-hour)

Simple 24-hour time picker with hours and minutes. Click the input to open the time selection popup.

@if (basicSelectedTime) {
Selected: {{ formatTimeDisplay(basicSelectedTime, true, false) }}
Minutes since midnight: {{ getTimeInMinutes(basicSelectedTime) }}
} 
<chronica-time-picker
  [(ngModel)]="basicSelectedTime"
  [config]="{
    format24Hour: true,
    showSeconds: false,
    colorTheme: 'blue'
  }"
  placeholder="Select time"
  (timeChange)="onBasicTimeChanged($event)">
</chronica-time-picker>

2. 12-Hour Format with AM/PM

12-hour format with AM/PM selection. Perfect for user-friendly time input in everyday applications.

@if (twelveHourTime) {
Selected: {{ formatTimeDisplay(twelveHourTime, false, false) }}
24-hour format: {{ formatTimeDisplay(twelveHourTime, true, false) }}
} 
<chronica-time-picker
  [(ngModel)]="twelveHourTime"
  [config]="{
    format24Hour: false,
    colorTheme: 'blue'
  }"
  placeholder="Select time (12-hour format)">
</chronica-time-picker>

3. Precision Time with Seconds

Precise time selection including seconds. Useful for scheduling, time tracking, and scientific applications.

@if (timeWithSeconds) {
Selected: {{ formatTimeDisplay(timeWithSeconds, true, true) }}
Total seconds since midnight: {{ getTimeInMinutes(timeWithSeconds) * 60 + (timeWithSeconds.seconds || 0) }}
} 
<chronica-time-picker
  [(ngModel)]="timeWithSeconds"
  [config]="{
    format24Hour: true,
    showSeconds: true,
    colorTheme: 'blue'
  }"
  placeholder="Select time with seconds">
</chronica-time-picker>

4. Business Hours Restrictions

Restrict time selection to business hours or specific time ranges. Perfect for appointment booking systems.

@if (restrictedTime) {
Selected: {{ formatTimeDisplay(restrictedTime, true, false) }}
Within business hours: ✅ Valid
} 
<chronica-time-picker
  [(ngModel)]="restrictedTime"
  [config]="{
    format24Hour: true,
    colorTheme: 'blue'
  }"
  [minTime]="{ hours: 9, minutes: 0 }"
  [maxTime]="{ hours: 17, minutes: 30 }">
</chronica-time-picker>

5. Form Integration

Seamless integration with Angular forms using ngModel and ControlValueAccessor pattern.

Form Valid: {{ timeForm.valid ? '✅' : '❌' }}
Form Value: {{ formSelectedTime | json }} 
<chronica-time-picker
  name="meetingTime"
  [(ngModel)]="formSelectedTime"
  [config]="{
    format24Hour: false,
    colorTheme: 'blue'
  }"
  required>
</chronica-time-picker>

6. Custom Step Intervals

Customize minute and second intervals for specific use cases like appointment scheduling or time tracking.

@if (customStepTime) {
Selected: {{ formatTimeDisplay(customStepTime, true, true) }}
Step intervals: 15-minute, 30-second blocks
} 
<chronica-time-picker
  [(ngModel)]="customStepTime"
  [config]="{
    format24Hour: true,
    showSeconds: true,
    minuteStep: 15,
    secondStep: 30,
    colorTheme: 'blue'
  }">
</chronica-time-picker>

7. Dark Theme

Modern dark theme for night-time applications and dark mode interfaces.

@if (darkThemeTime) {
Selected: {{ formatTimeDisplay(darkThemeTime, true, false) }}
Theme: Dark mode
} 
<chronica-time-picker
  [(ngModel)]="darkThemeTime"
  [config]="{
    theme: 'dark',
    colorTheme: 'blue',
    format24Hour: true
  }">
</chronica-time-picker>

Configuration Options

Property Type Default Description
format24Hour boolean true Use 24-hour format (true) or 12-hour with AM/PM (false)
showSeconds boolean false Include seconds selection in the time picker
minuteStep number 1 Step interval for minutes (e.g., 15 for 15-min blocks)
secondStep number 1 Step interval for seconds
minTime TimeValue null Minimum selectable time
maxTime TimeValue null Maximum selectable time
colorTheme string 'blue' Color theme: blue, purple, green, red, orange, teal, pink, indigo
theme string 'light' UI theme: light or dark
placeholder string 'Select time' Placeholder text for the time input field

Key Features

  • 12-hour and 24-hour format support
  • Optional seconds selection for precision timing
  • Customizable minute/second step intervals
  • Min/max time restrictions for business hours
  • Popup-based time selection interface
  • Angular forms integration (ngModel & Reactive)
  • Multiple color themes & dark mode support
  • Quick actions (Now, Clear) for convenience
  • Responsive design for mobile and desktop
