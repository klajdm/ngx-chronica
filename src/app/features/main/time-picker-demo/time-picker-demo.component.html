Time Picker

Interactive time picker component for selecting hours, minutes, and seconds. Supports both 12-hour and 24-hour formats with customizable intervals and restrictions.

Basic Time Picker (24-hour)

Code Example

<chronica-time-picker
  [(ngModel)]="basicSelectedTime"
  [config]="basicConfig"
  (timeChange)="onBasicTimeChanged($event)"
></chronica-time-picker>
basicConfig = {
  format24Hour: true,
  showSeconds: false
};

Simple 24-hour time picker with hours and minutes. Click the input to open the time selection popup.

Live Demo

12-Hour Format with AM/PM

Code Example

<chronica-time-picker
  [(ngModel)]="twelveHourTime"
  [config]="twelveHourConfig"
  (timeChange)="onTwelveHourTimeChanged($event)"
></chronica-time-picker>
twelveHourConfig = {
  format24Hour: false,
  colorTheme: 'purple'
};

12-hour format with AM/PM selection. Perfect for user-friendly time input.

Time Range Restrictions

Code Example

restrictedConfig = {
  format24Hour: true,
  colorTheme: 'orange'
};
minTime = { hours: 9, minutes: 0 }; // 9:00 AM
maxTime = { hours: 17, minutes: 30 }; // 5:30 PM

Restrict time selection to business hours or specific time ranges.

Live Demo

Only times between 9:00 AM and 5:30 PM are selectable

Form Integration

Code Example

<form>
  <div class="form-group">
    <label>Meeting Time</label>
    <chronica-time-picker
      [(ngModel)]="formSelectedTime"
      [config]="formConfig"
      name="meetingTime"
    ></chronica-time-picker>
  </div>
</form>

Seamless integration with Angular forms using ngModel or reactive forms.

Custom Step Intervals

Code Example

customStepConfig = {
  format24Hour: true,
  showSeconds: true,
  minuteStep: 15, // 15-minute intervals
  secondStep: 30, // 30-second intervals
  colorTheme: 'red'
};

Customize minute and second intervals for specific use cases like appointment scheduling.

Key Features

  • 12-hour and 24-hour format support
  • Optional seconds selection
  • Customizable minute/second intervals
  • Min/max time restrictions
  • Angular forms integration (ngModel & Reactive)
  • Multiple color themes & dark mode
  • Keyboard navigation & accessibility
  • Quick actions (Now, Clear)
