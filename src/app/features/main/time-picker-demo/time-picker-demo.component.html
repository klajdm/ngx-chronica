Time Picker Component

Interactive time picker component for selecting hours, minutes, and seconds. Supports both 12-hour and 24-hour formats with customizable intervals and restrictions. Perfect for appointment scheduling, meeting setup, and time-sensitive applications.

1. Basic Time Picker (24-hour)

Simple 24-hour time picker with hours and minutes. Click the input to open the time selection popup.

@if (basicSelectedTime) {
Selected: {{ formatTimeDisplay(basicSelectedTime, true, false) }}
Minutes since midnight: {{ getTimeInMinutes(basicSelectedTime) }}
}

2. 12-Hour Format with AM/PM

12-hour format with AM/PM selection. Perfect for user-friendly time input in everyday applications.

@if (twelveHourTime) {
Selected: {{ formatTimeDisplay(twelveHourTime, false, false) }}
24-hour format: {{ formatTimeDisplay(twelveHourTime, true, false) }}
}

3. Precision Time with Seconds

Precise time selection including seconds. Useful for scheduling, time tracking, and scientific applications.

@if (timeWithSeconds) {
Selected: {{ formatTimeDisplay(timeWithSeconds, true, true) }}
Total seconds since midnight: {{ getTimeInMinutes(timeWithSeconds) * 60 + (timeWithSeconds.seconds || 0) }}
}
