Locales / Internationalization

NGX-Chronica ships with 11 built-in locale configurations covering month names, day names, date formats, and week-start conventions. Pass a locale code string or a full ChronicaLocale object to any component.

ChronicaLocale Interface

Property Type Description
monthNames string[] (12) Full month names, January–December
dayNames string[] (7) Full day names, Sunday–Saturday
dayNamesShort string[] (7) Abbreviated day names shown in the calendar header
todayLabel string Label for the "Today" button
weekStartsOn 0 | 1 | … | 6 First day of the week (0 = Sunday, 1 = Monday)
dateFormat string Date format pattern used in the input field (e.g. dd/MM/yyyy)
