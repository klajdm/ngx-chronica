Date Range Picker

Interactive date range picker with popup calendar for selecting start and end dates. Features quick select presets, range highlighting, and form integration.

Basic Date Range

Code Example

<chronica-date-range
  [(ngModel)]="basicSelectedRange"
  [config]="basicConfig"
  (dateRangeChange)="onBasicRangeChanged($event)"
></chronica-date-range>

Simple date range picker with default blue theme. Click the input to open the calendar popup and select a date range.

Live Demo

Custom Theme

Code Example

<chronica-date-range
  [(ngModel)]="themedSelectedRange"
  [config]="themedConfig"
  (dateRangeChange)="onThemedRangeChanged($event)"
></chronica-date-range>
themedConfig = {
  theme: 'light',
  colorTheme: 'purple'
};

Date range picker with purple color theme. Multiple color themes are available.

Date Range Restrictions

Code Example

restrictedConfig = {
  theme: 'light',
  colorTheme: 'green',
  minDate: new Date(2024, 0, 1),
  maxDate: new Date(2024, 11, 31)
};

Restrict date selection to a specific range. Dates outside the range are disabled.

Live Demo

Form Integration

Code Example

<form>
  <div class="form-group">
    <label>Project Duration</label>
    <chronica-date-range
      [(ngModel)]="formSelectedRange"
      [config]="formConfig"
      name="projectDuration"
    ></chronica-date-range>
  </div>
</form>

Seamless integration with Angular forms using ngModel or reactive forms.

Key Features

  • Date range selection with visual feedback
  • Quick select presets (Today, This Week, This Month)
  • Hover preview for range selection
  • Min/max date restrictions
  • Angular forms integration (ngModel & Reactive)
  • Multiple color themes & dark mode
  • Keyboard navigation & accessibility
  • Localization & internationalization
