Date Range Picker Component

Interactive date range picker with popup calendar for selecting start and end dates. Features quick select presets, range highlighting, form integration, and business day filtering. Perfect for booking systems, project planning, and reporting periods.

1. Basic Date Range Picker

Simple date range picker with default blue theme. Click the input to open the calendar popup and select a date range.

Selected Range: {{ basicSelectedRange.startDate | date: 'mediumDate' }} - {{ basicSelectedRange.endDate | date: 'mediumDate' }}
Duration: {{ getDaysDifference(basicSelectedRange) }} days 
<chronica-date-range
  [(ngModel)]="basicSelectedRange"
  [config]="{
    theme: 'light',
    colorTheme: 'blue'
  }"
  placeholder="Select date range"
  (dateRangeChange)="onBasicRangeChanged($event)">
</chronica-date-range>

2. Custom Color Theme

Date range picker with purple color theme. Multiple color themes are available for brand consistency.

Selected Range: {{ themedSelectedRange.startDate | date: 'mediumDate' }} - {{ themedSelectedRange.endDate | date: 'mediumDate' }}
Duration: {{ getDaysDifference(themedSelectedRange) }} days 
<chronica-date-range
  [(ngModel)]="themedSelectedRange"
  [config]="{
    theme: 'light',
    colorTheme: 'purple'
  }"
  placeholder="Select date range (purple theme)">
</chronica-date-range>

3. Date Range Restrictions

Restrict date selection to a specific range. Dates outside the allowed range are disabled and cannot be selected.

Selected Range: {{ restrictedSelectedRange.startDate | date: 'mediumDate' }} - {{ restrictedSelectedRange.endDate | date: 'mediumDate' }}
Restriction: ✅ Within allowed range (2024) 
<chronica-date-range
  [(ngModel)]="restrictedSelectedRange"
  [config]="{
    theme: 'light',
    colorTheme: 'green'
  }"
  [minDate]="new Date(2024, 0, 1)"
  [maxDate]="new Date(2024, 11, 31)">
</chronica-date-range>

4. Form Integration

Seamless integration with Angular forms using ngModel and ControlValueAccessor pattern.

Form Valid: {{ rangeForm.valid ? '✅' : '❌' }}
Form Value: {{ formSelectedRange | json }} 
<chronica-date-range
  name="projectDuration"
  [(ngModel)]="formSelectedRange"
  [config]="{
    theme: 'light',
    colorTheme: 'orange'
  }"
  required>
</chronica-date-range>

5. Business Days Only

Disable weekends for business day selection only. Useful for project planning, scheduling, and business operations.

Selected Range: {{ businessDaysRange.startDate | date: 'mediumDate' }} - {{ businessDaysRange.endDate | date: 'mediumDate' }}
Business Days: {{ getBusinessDaysCount(businessDaysRange) }} working days 
<chronica-date-range
  [(ngModel)]="businessDaysRange"
  [config]="{
    theme: 'light',
    colorTheme: 'red',
    disabledDates: this.generateWeekendDates()
  }">
</chronica-date-range>

6. Quick Select Presets

Pre-defined date ranges for common selections like "Last 7 days", "This month", or "This quarter".

Selected Range: {{ presetRange.startDate | date: 'mediumDate' }} - {{ presetRange.endDate | date: 'mediumDate' }}
Quick Selection: {{ getPresetName(presetRange) }} 
<chronica-date-range
  [(ngModel)]="presetRange"
  [config]="{
    theme: 'light',
    colorTheme: 'indigo',
    showPresets: true,
    presets: [
      { label: 'Last 7 days', range: this.getLastNDays(7) },
      { label: 'Last 30 days', range: this.getLastNDays(30) },
      { label: 'This month', range: this.getCurrentMonth() }
    ]
  }">
</chronica-date-range>

Configuration Options

Property Type Default Description
theme 'light' | 'dark' 'light' Visual theme mode
colorTheme string 'blue' Color theme: blue, purple, green, red, orange, teal, pink, indigo
minDate Date null Minimum selectable date
maxDate Date null Maximum selectable date
disabledDates Date[] [] Array of disabled dates
showPresets boolean false Show quick select presets
presets PresetRange[] [] Custom preset ranges
showTime boolean false Include time selection
format string 'MM/dd/yyyy' Date display format
closeOnSelect boolean true Close popup after range selection

Key Features

  • Date range selection with visual feedback
  • Quick select presets for common ranges
  • Hover preview for range selection
  • Min/max date restrictions
  • Business day filtering (exclude weekends)
  • Angular forms integration (ngModel & Reactive)
  • Multiple color themes & dark mode support
  • Range highlighting with start/end markers
  • Customizable date format & localization
