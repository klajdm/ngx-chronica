Datepicker Component

Interactive date picker with popup calendar for forms and user input. Available with built-in input styling or custom trigger elements. Features multiple themes, date restrictions, form integration, and accessibility support for modern web applications.

Control where the calendar popup appears relative to the trigger using the popupPosition input. 'auto' (default) opens below the input and flips to above when there's not enough space. 'top' always opens above. 'bottom' always opens below.
