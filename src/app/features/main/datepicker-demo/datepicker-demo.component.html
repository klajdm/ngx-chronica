Datepicker

Interactive date picker with popup calendar for forms and user input. Click any input to open the calendar popup.

Basic Datepicker

Code Example

<chronica-datepicker
  [selectedDate]="basicSelectedDate"
  [config]="basicConfig"
  (dateSelected)="onBasicDateSelected($event)"
></chronica-datepicker>

Simple datepicker with default blue theme. Click the input to open the calendar popup.

Live Demo

Custom Theme

Code Example

<chronica-datepicker
  [selectedDate]="themedSelectedDate"
  [config]="themedConfig"
  (dateSelected)="onThemedDateSelected($event)"
></chronica-datepicker>
themedConfig = {
  theme: 'light',
  colorTheme: 'purple'
};

Datepicker with purple color theme. Multiple color themes are available.

Live Demo

Selected: {{ themedSelectedDate | date: 'mediumDate' }}

Date Range Restrictions

Code Example

restrictedConfig = {
  theme: 'light',
  colorTheme: 'green',
  minDate: new Date(2024, 0, 1),
  maxDate: new Date(2024, 11, 31)
};

Restrict date selection to a specific range. Dates outside the range are disabled.

Live Demo

Form Integration

Code Example

<form>
  <div class="form-group">
    <label>Appointment Date</label>
    <chronica-datepicker
      [(ngModel)]="formSelectedDate"
      [config]="formConfig"
      name="appointmentDate"
    ></chronica-datepicker>
  </div>
</form>

Seamless integration with Angular forms using ngModel or reactive forms.

Disabled Dates

Code Example

disabledDatesConfig = {
  theme: 'light',
  colorTheme: 'red',
  disabledDates: [
    new Date(2024, 11, 25), // Christmas
    new Date(2024, 0, 1),   // New Year
    new Date(2024, 6, 4)    // July 4th
  ]
};

Disable specific dates like holidays or unavailable days. Disabled dates cannot be selected.
