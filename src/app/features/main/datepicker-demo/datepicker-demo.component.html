Datepicker Component

Interactive date picker with popup calendar for forms and user input. Available with built-in input styling or custom trigger elements. Features multiple themes, date restrictions, form integration, and accessibility support for modern web applications.

1. Default Input Datepicker

Built-in styled input with calendar popup. Simple date picker with default blue theme and consistent input styling.

@if (defaultSelectedDate) {
Selected Date: {{ defaultSelectedDate | date: 'mediumDate' }}
} 
<chronica-datepicker
  [selectedDate]="defaultSelectedDate"
  [config]="{
    theme: 'light',
    colorTheme: 'blue'
  }"
  [placeholder]="'Choose a date'"
  (dateSelected)="onDefaultDateSelected($event)">
</chronica-datepicker>

3. Date Restrictions

Min/max date ranges and disabled specific dates. Restrict date selection to specific ranges or disable holidays and unavailable dates.

Only dates in 2024 are selectable

Christmas, New Year, and July 4th are disabled

Restricted Range: {{ restrictedSelectedDate | date: 'mediumDate' }}
Restriction: ✅ Within allowed range (2024)
Disabled Dates: {{ disabledDatesSelected | date: 'mediumDate' }} 
// Date range restriction
restrictedConfig = {
  theme: 'light',
  colorTheme: 'blue',
  minDate: new Date(2024, 0, 1),
  maxDate: new Date(2024, 11, 31)
};

// Disabled specific dates
disabledDatesConfig = {
  theme: 'light',
  colorTheme: 'blue',
  disabledDates: [
    new Date(2024, 11, 25), // Christmas
    new Date(2024, 0, 1),   // New Year
    new Date(2024, 6, 4)    // July 4th
  ]
};

4. Form Integration

Seamless integration with Angular forms using ngModel and ControlValueAccessor pattern. Perfect for forms and validation workflows.

Form Valid: {{ dateForm.valid ? '✅' : '❌' }}
Form Value: {{ formSelectedDate | date: 'mediumDate' }} 
<chronica-datepicker
  [(ngModel)]="formSelectedDate"
  [config]="{
    theme: 'light',
    colorTheme: 'blue'
  }"
  name="appointmentDate"
  required>
</chronica-datepicker>

Configuration Options

Property Type Default Description
selectedDate Date | null null Currently selected date
hideInput boolean false Hide the default input and use custom trigger
placeholder string 'Select date' Placeholder text for the input
config.theme 'light' | 'dark' 'light' Light or dark theme
config.colorTheme string 'blue' Color theme: blue, green, purple, red, orange, teal, pink, indigo
config.minDate Date undefined Minimum selectable date
config.maxDate Date undefined Maximum selectable date
config.disabledDates Date[] [] Array of disabled dates
config.showTodayButton boolean true Show "Today" button in calendar
config.firstDayOfWeek number 0 First day of week (0 = Sunday, 1 = Monday)

Key Features

  • Built-in styled input or custom trigger elements
  • Multiple color themes & dark mode support
  • Date range restrictions & disabled dates
  • Popup calendar with month/year navigation
  • Today button for quick date selection
  • Angular forms integration (ngModel & Reactive)
  • Focus states without hover effects
  • Customizable placeholder text
  • Configurable first day of week
