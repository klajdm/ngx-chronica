Documentation

Comprehensive guide to all features and capabilities of NGX-Chronica - the most complete date/time component library for Angular.

Core Features

6 Specialized Components

Complete toolkit covering all date/time selection scenarios: Datepicker, Date Range, Inline Calendar, Time Picker, DateTime Picker, and Duration Picker.

  • • Single date selection
  • • Date range selection
  • • Time selection (12h/24h)
  • • Combined date + time
  • • Duration/time span selection
  • • Always-visible calendar

Full Forms Integration

Seamless integration with Angular forms through ControlValueAccessor implementation.

  • • Reactive Forms support
  • • Template-driven Forms support
  • • Two-way binding with [(ngModel)]
  • • Form validation support
  • • Disabled state handling
  • • Touch/dirty state tracking

Advanced Theming

8 built-in color themes with light/dark mode support and CSS custom properties.

  • • 8 color themes (Blue, Green, Purple, Red, etc.)
  • • Light/Dark mode auto-detection
  • • CSS custom properties for customization
  • • Consistent design system
  • • Easy theme switching

Internationalization

11 built-in locales with support for custom locales and RTL languages.

  • • 11 built-in locales (EN, ES, FR, DE, IT, PT, ZH, JA, KO, RU, AR)
  • • Custom locale support
  • • Configurable first day of week
  • • Localized month/day names
  • • Date format customization

Display Modes

🔽 Popup Mode

Calendar appears in an overlay popup when triggered, perfect for forms and space-constrained layouts.

  • • Angular CDK Overlay positioning
  • • Custom trigger elements
  • • Backdrop click to close
  • • Keyboard navigation (Escape to close)
  • • Smart positioning (auto-flip)

📌 Inline Mode

Calendar is always visible inline with your content, ideal for dashboards and dedicated date selection pages.

  • • Always visible
  • • No trigger required
  • • Embeddable in any layout
  • • Perfect for dashboards
  • • Customizable size

API Reference

Complete reference for all component inputs, outputs, and configuration interfaces.

DatePicker Component

Inputs

Property Type Default Description
selectedDate Date | null null Currently selected date
config ChronicaCalendarConfig DEFAULT_CALENDAR_CONFIG Configuration object for calendar behavior
locale ChronicaLocale | string 'en-US' Locale for internationalization
initialMonth number - Initial month to display (0-11)
initialYear number - Initial year to display
popupPosition 'bottom' | 'top' | 'auto' 'auto' Position of the popup calendar
hideInput boolean false Hide the input field (custom trigger)
placeholder string 'Select date' Placeholder text for input

Outputs

Event Type Description
dateSelected EventEmitter<Date> Emitted when a date is selected
monthChanged EventEmitter<{month: number; year: number}> Emitted when month/year changes
calendarEvent EventEmitter<ChronicaEvent> Emitted for calendar-related events

Date Range Component

Inputs

Property Type Default Description
config ChronicaCalendarConfig DEFAULT_CALENDAR_CONFIG Configuration object
locale ChronicaLocale | string 'en-US' Locale for internationalization
placeholder string 'Select date range' Placeholder text
minDate Date | null null Minimum selectable date
maxDate Date | null null Maximum selectable date
disabled boolean false Disable the component
required boolean false Mark as required field

Outputs

Event Type Description
dateRangeChange EventEmitter<ChronicaDateRange> Emitted when date range changes
calendarEvent EventEmitter<ChronicaEvent> Emitted for calendar events

Inputs

Property Type Default Description

maxDuration ChronicaDurationValue | null null Maximum duration
disabled boolean false Disable the component

Configuration Interfaces

ChronicaCalendarConfig

Property Type Description
theme 'light' | 'dark' | 'auto' Visual theme mode
colorTheme 'blue' | 'green' | 'purple' | 'red' | 'orange' | 'teal' | 'pink' | 'indigo' Color theme for primary colors
minDate Date Minimum selectable date
maxDate Date Maximum selectable date
disabledDates Date[] Array of disabled dates
firstDayOfWeek number First day of week (0=Sunday, 1=Monday)
showTodayButton boolean Show today button
showNavigation boolean Show navigation arrows
closeAfterSelection boolean Close popup after date selection

TimePickerConfig

Property Type Description
format24Hour boolean Use 24-hour format (true) or 12-hour with AM/PM (false)
showSeconds boolean Show seconds selector
minuteStep number Minute step increment (e.g., 15 for 15-minute intervals)
secondStep number Second step increment

DurationPickerConfig

Property Type Description
showDays boolean Show days selector
showHours boolean Show hours selector
showMinutes boolean Show minutes selector
showSeconds boolean Show seconds selector
stepDays number Day step increment
stepHours number Hour step increment
stepMinutes number Minute step increment
allowZero boolean Allow zero duration

Type Definitions

ChronicaTimeValue

interface ChronicaTimeValue {
  hours: number;      // 0-23
  minutes: number;    // 0-59
  seconds?: number;   // 0-59 (optional)
  period?: 'AM' | 'PM'; // For 12h format
}

ChronicaDurationValue

interface ChronicaDurationValue {
  days?: number;
  hours?: number;
  minutes?: number;
  seconds?: number;
}

ChronicaDateRange

interface ChronicaDateRange {
  startDate: Date | null;
  endDate: Date | null;
}

ChronicaDateTimeValue

interface ChronicaDateTimeValue {
  date: Date | null;
  time: ChronicaTimeValue | null;
}
