DateTime Picker Component

Combined date and time picker component for comprehensive datetime selection. Features integrated calendar and time picker with customizable formats, themes, and form integration. Perfect for appointment scheduling, event planning, and any application requiring precise datetime input with a unified interface.

1. Basic DateTime Picker (24-hour format)

Combined date and time picker with 24-hour format. Select both date and time in a single unified interface with side-by-side calendar and time controls.

@if (basicSelectedDateTime) {
Selected DateTime: {{ formatDateTimeDisplay(basicSelectedDateTime) }}
Date: {{ basicSelectedDateTime.date | date: 'mediumDate' }}
Time: {{ formatTimeDisplay(basicSelectedDateTime.time, true) }}
} 
<chronica-datetime-picker
  [dateTimeValue]="basicSelectedDateTime"
  [config]="{
    theme: 'light',
    colorTheme: 'blue',
    format24Hour: true,
    showSeconds: false
  }"
  [placeholder]="'Select date and time'"
  (dateTimeChange)="onBasicDateTimeChanged($event)">
</chronica-datetime-picker>

2. 12-Hour Format with AM/PM

DateTime picker configured for 12-hour time format with AM/PM selector. Ideal for applications targeting users familiar with standard clock format.

@if (twelveHourDateTime) {
Selected DateTime: {{ formatDateTimeDisplay(twelveHourDateTime) }}
12-Hour Format: {{ formatTimeDisplay(twelveHourDateTime.time, false) }}
Valid Business Hours: {{ isValidAppointmentTime(twelveHourDateTime) ? '✅ Valid' : '❌ Outside business hours' }}
} 
<chronica-datetime-picker
  [dateTimeValue]="twelveHourDateTime"
  [config]="{
    theme: 'light',
    colorTheme: 'blue',
    format24Hour: false,
    showSeconds: false
  }"
  (dateTimeChange)="onTwelveHourDateTimeChanged($event)">
</chronica-datetime-picker>

3. Precise Time with Seconds

DateTime picker with seconds precision for applications requiring exact timing. Includes additional time column for second selection with configurable step intervals.

@if (dateTimeWithSeconds) {
Selected DateTime: {{ formatDateTimeDisplay(dateTimeWithSeconds) }}
With Seconds: {{ formatTimeDisplay(dateTimeWithSeconds.time, true, true) }}
Total Minutes: {{ getDateTimeInMinutes(dateTimeWithSeconds) }} minutes since midnight
} 
<chronica-datetime-picker
  [dateTimeValue]="dateTimeWithSeconds"
  [config]="{
    theme: 'light',
    colorTheme: 'blue',
    format24Hour: true,
    showSeconds: true
  }"
  (dateTimeChange)="onDateTimeWithSecondsChanged($event)">
</chronica-datetime-picker>

4. Custom Trigger Element

Hide the default input and use any custom element as a trigger for the datetime picker popup. Perfect for integrating with custom designs and button styles.

{{ customTriggerDateTime ? formatDateTimeDisplay(customTriggerDateTime) : 'Schedule Meeting' }}
@if (customTriggerDateTime) {
Meeting Scheduled: {{ formatDateTimeDisplay(customTriggerDateTime) }}
Trigger: Custom meeting scheduler button
} 
<chronica-datetime-picker
  [dateTimeValue]="customTriggerDateTime"
  [config]="config"
  [hideInput]="true"
  (dateTimeChange)="onCustomTriggerDateTimeChanged($event)">
  <div class="custom-trigger">
    <svg>...</svg>
    {{ customTriggerDateTime ? 
        formatDateTimeDisplay(customTriggerDateTime) : 
        'Schedule Meeting' }}
  </div>
</chronica-datetime-picker>

5. Date Restrictions

DateTime picker with date range restrictions. Limit selectable dates to specific periods for booking systems, appointment scheduling, or availability-based applications.

@if (restrictedDateTime) {
Selected DateTime: {{ formatDateTimeDisplay(restrictedDateTime) }}
Restriction: ✅ Within allowed range (2024)
Date Validation: Dates outside 2024 are disabled
} 
restrictedConfig = {
  theme: 'light',
  colorTheme: 'blue',
  format24Hour: true,
  showSeconds: false,
  minDate: new Date(2024, 0, 1),   // January 1, 2024
  maxDate: new Date(2024, 11, 31)  // December 31, 2024
};

6. Form Integration

Seamless integration with Angular forms using ngModel and ControlValueAccessor pattern. Perfect for complex forms requiring datetime input with validation and data binding.

Form Valid: {{ datetimeForm.valid ? '✅' : '❌' }}
Form Value: {{ formatDateTimeDisplay(formSelectedDateTime) }}
Business Hours Valid: {{ isValidAppointmentTime(formSelectedDateTime) ? '✅ Valid' : '❌ Outside hours' }} 
<chronica-datetime-picker
  [(ngModel)]="formSelectedDateTime"
  [config]="{
    theme: 'light',
    colorTheme: 'blue',
    format24Hour: false
  }"
  name="appointmentDateTime"
  required>
</chronica-datetime-picker>

7. Dark Theme

Dark theme variant for datetime picker. Perfect for dark mode applications and night-time interfaces with consistent styling across calendar and time controls.

Theme: Dark mode with unified styling 
<chronica-datetime-picker
  [dateTimeValue]="darkThemeDateTime"

  }">
</chronica-datetime-picker>

Configuration Options

Property Type Default Description
dateTimeValue DateTimeValue | null null Currently selected date and time
enableTimePicker boolean true Enable/disable time selection (date-only mode)
format24Hour boolean true Use 24-hour format or 12-hour with AM/PM
showSeconds boolean false Show seconds in time selection
hideInput boolean false Hide the default input and use custom trigger
placeholder string 'Select date and time' Placeholder text for the input
config.theme 'light' | 'dark' 'light' Light or dark theme
config.colorTheme string 'blue' Color theme: blue, green, purple, red, orange, teal, pink, indigo
config.minDate Date undefined Minimum selectable date
config.maxDate Date undefined Maximum selectable date
minuteStep number 1 Minute selection step interval
secondStep number 1 Second selection step interval

Key Features

  • Combined date and time selection in one interface
  • 24-hour and 12-hour time format support
  • Optional seconds precision for exact timing
  • Date-only mode with time picker disabled
  • Built-in input or custom trigger elements
  • Date range restrictions and validation
  • Multiple color themes & dark mode
  • Angular forms integration (ngModel & Reactive)
  • Responsive design for mobile and desktop
  • Keyboard navigation and accessibility
