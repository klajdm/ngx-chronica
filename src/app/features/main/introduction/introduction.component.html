NGX-Chronica

A comprehensive suite of 6 specialized date and time picker components for Angular. Fill the gaps left by Angular Material with production-ready components.

Why NGX-Chronica?

Angular Material lacks native Time Picker, DateTime Picker, and Duration Picker components. NGX-Chronica addresses these critical gaps with a complete toolkit of date/time components that are production-ready, fully typed, and accessible.

6 Specialized Components

📅

DatePicker

Single date selection with popup

Forms, filters, date inputs
📆

DateRange

Start/end date selection

Booking systems, reports
🗓️

InlineCalendar

Always-visible calendar

Dashboards, embedded
⏰

TimePicker

Time selection (12h/24h)

Appointments, schedules
📅⏰

DateTimePicker

Combined date + time

Event scheduling
⏱️

DurationPicker

Time span selection

Task estimation, timers

Key Features

  • ✓ 8 Color Themes: Blue, Green, Purple, Red, Orange, Teal, Pink, Indigo
  • ✓ 11 Built-in Locales: EN, ES, FR, DE, IT, PT, ZH, JA, KO, RU + custom
  • ✓ Dark Mode Support: Auto-detect or force light/dark themes
  • ✓ Smart Validation: Min/max dates, disabled dates, time restrictions
  • ✓ Form Integration: Full ControlValueAccessor support
  • ✓ Standalone Components: Works with standalone or NgModule apps
  • ✓ Accessibility: WCAG compliant, keyboard navigation, ARIA labels
  • ✓ TypeScript First: Comprehensive type definitions included
