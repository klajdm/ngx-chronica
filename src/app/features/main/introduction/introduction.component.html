NGX-Chronica

A comprehensive suite of 6 specialized date and time picker components for Angular. Fill critical gaps in the Angular ecosystem with production-ready components.

Why NGX-Chronica?

The Angular ecosystem lacks robust, production-ready Date & Time Picker components. NGX-Chronica addresses these critical gaps with a complete toolkit of date/time components that are production-ready, fully typed, and accessible.

NGX-Chronica provides 6 specialized components covering every date and time selection scenario-from simple date picking to complex duration selection. All components share a consistent API, theming system, and accessibility standards.

Features

  • 🗓️ 6 Specialized Components - DatePicker, Date Range, Inline Calendar, Time Picker, DateTime Picker, and Duration Picker.
  • 🎨 8 Beautiful Themes - Light and dark mode with Blue, Green, Purple, Red, Orange, Teal, Pink, or Indigo.
  • 📝 Seamless Form Integration - Full ControlValueAccessor for Reactive and Template-driven forms.
  • 🌍 Internationalization - 11 built-in locales (EN, ES, FR, DE, IT, PT, ZH, JA, KO, RU, AR) plus custom support.
  • 🚫 Smart Validation - Min/max constraints, disabled dates, time restrictions, and business day filtering.
  • ♿ Accessibility - WCAG 2.1 AA compliant with keyboard navigation and screen reader support.
  • ⚡ Standalone Components - Modern Angular with zero setup for standalone or NgModule apps.
  • 🎯 TypeScript First - Comprehensive type definitions and strict mode compliance.
  • 📱 Mobile Responsive - Touch-friendly with optimized layouts and gesture support.
  • 🔧 Highly Customizable - Extensive options, CSS variables, and flexible APIs.

Built with Angular CDK for robust overlay positioning. Zero external dependencies-no Moment.js or date-fns. Compiled to CommonJS and ESM.

Quick Preview

./MyCalendar.component.ts
import { Component } from '@angular/core';
import { ChronicaInlineCalendarComponent } from 'ngx-chronica';

@Component({
  selector: 'app-my-calendar',
  standalone: true,
  imports: [ChronicaInlineCalendarComponent],
  template: `
    <chronica-inline-calendar
      [selectedDate]="selected"
      (dateSelected)="onDateSelected($event)"
    />
  `
})
export class MyCalendarComponent {
  selected: Date | null = new Date();

  onDateSelected(date: Date) {
    console.log('Selected:', date);
  }
}
