Inline Calendar Demo

Always-visible calendar for date selection and embedding in pages or forms.

Example

<chronica-datepicker
	[selectedDate]="selectedDate"
	[config]="{ theme: 'light', colorTheme: 'indigo' }"
	[displayMode]="'inline'"
	(dateSelected)="onDateSelected($event)"
></chronica-datepicker>

Inline mode is useful for dashboards, booking UIs and forms where a persistent calendar is required.
