Inline Calendar Component

Always-visible calendar for date selection and embedding in pages or forms. Perfect for dashboards, booking interfaces, and any application where calendar visibility is essential. No popup required - seamlessly integrates into your layout.

1. Basic Inline Calendar

Simple inline calendar with default blue theme. Always visible and ready for interaction without any popup overlay. 

<chronica-inline-calendar
  [selectedDate]="basicSelectedDate"
  [config]="{
    theme: 'light',
    colorTheme: 'blue'
  }"
  (dateSelected)="onBasicDateSelected($event)"
  (monthChanged)="onMonthChanged($event)">
</chronica-inline-calendar>
@if (basicSelectedDate) {
Selected Date: {{ basicSelectedDate | date: 'mediumDate' }}
}

2. Compact Version

<chronica-inline-calendar

@if (compactSelectedDate) {

3. Date Range Restrictions

Restrict date selection to a specific range. Dates outside the allowed range are disabled and cannot be selected. 

<chronica-inline-calendar
  [selectedDate]="restrictedSelectedDate"
  [config]="{
    theme: 'light',
    colorTheme: 'blue',
    minDate: new Date(2024, 0, 1),
    maxDate: new Date(2024, 11, 31)
  }"
  (dateSelected)="onRestrictedDateSelected($event)">
</chronica-inline-calendar>

Only dates in 2024 are selectable

@if (restrictedSelectedDate) {
Selected Date: {{ restrictedSelectedDate | date: 'mediumDate' }}
}

4. Weekend Disabled

Disable weekends for business applications where only weekdays are selectable. Perfect for scheduling work events. 

<chronica-inline-calendar
  [selectedDate]="weekendDisabledSelected"
  [config]="{
    theme: 'light',
    colorTheme: 'blue',
    disabledDates: this.generateWeekendDates()
  }"
  (dateSelected)="onWeekendDisabledSelected($event)">
</chronica-inline-calendar>

Weekends are disabled

@if (weekendDisabledSelected) {
Selected Date: {{ weekendDisabledSelected | date: 'mediumDate' }}
}

7. Multi-View Navigation & Navigation Guards

Click the month/year header button to cycle through three views: Month → Months (12-month grid) → Year (decade grid). Navigation arrows are automatically disabled when minDate or maxDate would be exceeded - the example below restricts selection to the 2020s. 

<chronica-inline-calendar
  [selectedDate]="decadeViewSelectedDate"
  [config]="{
    theme: 'light',
    colorTheme: 'blue',
    minDate: new Date(2020, 0, 1),
    maxDate: new Date(2029, 11, 31)
  }"
  (dateSelected)="onDecadeViewDateSelected($event)">
</chronica-inline-calendar>

<!-- Click the month/year header to cycle:
     Month view → Months grid → Year grid -->
@if (decadeViewSelectedDate) {
Selected Date: {{ decadeViewSelectedDate | date: 'mediumDate' }}
}

Tip: click the header button to cycle - Month → Months → Year.
