Inline Calendar Component

Always-visible calendar for date selection and embedding in pages or forms. Perfect for dashboards, booking interfaces, and any application where calendar visibility is essential. No popup required - seamlessly integrates into your layout.

1. Basic Inline Calendar

Simple inline calendar with default blue theme. Always visible and ready for interaction without any popup overlay. 

<chronica-inline-calendar
  [selectedDate]="basicSelectedDate"
  [config]="{
    theme: 'light',
    colorTheme: 'blue'
  }"
  (dateSelected)="onBasicDateSelected($event)"
  (monthChanged)="onMonthChanged($event)">
</chronica-inline-calendar>
Selected Date: {{ basicSelectedDate | date: 'mediumDate' }}

2. Compact Version

Compact version without the "Today" button for minimal space usage. Perfect for tight layouts and mobile interfaces. 

<chronica-inline-calendar
  [selectedDate]="compactSelectedDate"
  [config]="{
    theme: 'light',
    colorTheme: 'orange',
    showTodayButton: false
  }"
  (dateSelected)="onCompactDateSelected($event)">
</chronica-inline-calendar>
Selected Date: {{ compactSelectedDate | date: 'mediumDate' }}

3. Date Range Restrictions

Restrict date selection to a specific range. Dates outside the allowed range are disabled and cannot be selected. 

<chronica-inline-calendar
  [selectedDate]="restrictedSelectedDate"
  [config]="{
    theme: 'light',
    colorTheme: 'red',
    minDate: new Date(2024, 0, 1),
    maxDate: new Date(2024, 11, 31)
  }"
  (dateSelected)="onRestrictedDateSelected($event)">
</chronica-inline-calendar>

Only dates in 2024 are selectable

Selected Date: {{ restrictedSelectedDate | date: 'mediumDate' }}

4. Weekend Disabled

Disable weekends for business applications where only weekdays are selectable. Perfect for scheduling work events. 

<chronica-inline-calendar
  [selectedDate]="weekendDisabledSelected"
  [config]="{
    theme: 'light',
    colorTheme: 'purple',
    disabledDates: this.generateWeekendDates()
  }"
  (dateSelected)="onWeekendDisabledSelected($event)">
</chronica-inline-calendar>

Weekends are disabled

Selected Date: {{ weekendDisabledSelected | date: 'mediumDate' }}

5. Pre-selected Date

Calendar with today's date pre-selected. Useful for forms with default values and quick date selection workflows. 

<chronica-inline-calendar
  [selectedDate]="preSelectedDate"
  [config]="{
    theme: 'light',
    colorTheme: 'indigo'
  }"
  (dateSelected)="onPreSelectedDateSelected($event)">
</chronica-inline-calendar>

// Component initialization
preSelectedDate: Date | null = new Date();
Selected Date: {{ preSelectedDate | date: 'mediumDate' }}

Configuration Options

Property Type Default Description
selectedDate Date | null null Currently selected date
theme 'light' | 'dark' 'light' Visual theme mode
colorTheme string 'blue' Color theme: blue, purple, green, red, orange, teal, pink, indigo
minDate Date null Minimum selectable date
maxDate Date null Maximum selectable date
disabledDates Date[] [] Array of disabled dates
showTodayButton boolean true Show "Today" button for quick selection
showWeekNumbers boolean false Display week numbers in calendar
firstDayOfWeek number 0 First day of week (0=Sunday, 1=Monday)
