Inline Calendar

Always-visible calendar for date selection and embedding in pages or forms. Perfect for dashboards and booking interfaces.

Basic Inline Calendar

Code Example

<chronica-inline-calendar
  [selectedDate]="basicSelectedDate"
  [config]="basicConfig"
  (dateSelected)="onBasicDateSelected($event)"
></chronica-inline-calendar>

Simple inline calendar with default blue theme. Always visible and ready for interaction.

Live Demo

Selected: {{ basicSelectedDate | date: 'mediumDate' }}

Custom Theme

Code Example

<chronica-inline-calendar
  [selectedDate]="themedSelectedDate"
  [config]="themedConfig"
  (dateSelected)="onThemedDateSelected($event)"
></chronica-inline-calendar>
themedConfig = {
  theme: 'light',
  colorTheme: 'green'
};

Inline calendar with green color theme. Multiple color themes available.

Date Range Restrictions

Code Example

restrictedConfig = {
  theme: 'light',
  colorTheme: 'red',
  minDate: new Date(2024, 0, 1),
  maxDate: new Date(2024, 11, 31)
};

Restrict date selection to a specific range. Dates outside the range are disabled.

Live Demo

Weekend Disabled

Code Example

weekendDisabledConfig = {
  theme: 'light',
  colorTheme: 'purple',
  disabledDates: this.generateWeekendDates()
};

Disable weekends for business applications where only weekdays are selectable.
